
# DexOS: The Second Coming

This directory contains experiments for building and running the original
DexOS sources on modern systems.

The original DexOS source tree is intentionally left untouched.

The experiments are deliberately kept in separate directories so that
working intermediate stages remain available for reference.

## Experiment 000 - Rebuilding Hello.dex

Directory:

```
Apps_2026/Hello_c
```

The original DexOS v6 repository contains:

```
Apps_2012/Hello_c/Hello.asm
Apps_2012/Hello_c/Hello.dex
```

The initial experiment tests whether a current Linux version of FASM can
reproduce the original binary.

Run:

```
cd Apps_2026/Hello_c
./build.sh
```

The script assembles `Hello.asm` and compares the resulting binary with
the original `Hello.dex` using `cmp`.

A successful build ends with:

```
SUCCESS: Generated binary is byte-for-byte identical to the original.
```

Tested successfully on Linux Mint in October 2026.

## Experiment 001 - TinyCC generated code on DexOS

Directory:

```
Apps_2026/Hello_tcc
```

The first TinyCC experiment investigates whether C code generated by
TinyCC on Linux can be used to build a native DexOS application.

A small FASM startup module provides the DexOS executable header and
initialization and acts as a bridge between C code and the DexOS API.

The resulting program runs under DexOS, calls the native
`PrintString_0` function, prints text to the console and returns to the
DexOS command line.

The test program prints:

```
Hellorld!
```

This completes Step 01 of the TinyCC experiments.

TinyCC itself still runs on Linux. This is not a TinyCC port to DexOS.

See the README in `Apps_2026/Hello_tcc` for details.

## Further experiments

Further steps will be kept in separate directories on the same level:

```
Apps_2026/Hello_tcc
Apps_2026/step_02
Apps_2026/step_03
...
```

The immediate goal is to find out how far TinyCC generated code can be
used for native DexOS applications.

A possible later experiment is to build TinyCC itself as a DexOS
application.

Whether that will work remains to be seen.
