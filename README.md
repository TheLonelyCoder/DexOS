# DexOS - 2nd Round

This is my public fork of DexOS, originally created by Craig Bamford ("Dex").

For now, the goal is deliberately simple:

1. Preserve the original sources and history.
2. Build the original DexOS v6 sources on a modern Linux system.
3. Run and test the resulting system in QEMU.
4. Understand how DexOS works before changing it.

The original files, authorship and licensing information are intentionally
left untouched.

If that works, we'll see where it goes.
